# Painel do Carro

Launcher Android simples para usar um tablet como central multimídia: relógio, bateria e botões grandes
para Navegar (Waze/Maps), Música, Telefone, Todos os apps e Configurações. Segure um app na lista
para fixá-lo na tela inicial. Android 5.0+, 32 ou 64 bits, sem serviços do Google.

Compilar: `gradle assembleRelease` (JDK 17 + Android SDK 34). O APK sai em `app/build/outputs/apk/release/`.
